# Photoshop Session Manager (for Windows)

## Open tabs from the previous session

**License** MIT

**Author** senol41tr (https://ssarigul.tr)

**Tested on** CS 5.1 and CC 2026 (27.10.0) for Windows


### Installation

```markdown
1. Open Photoshop
2. File > Scripts > Browse...
3. Locate PhotoshopSessionManager.jsx
4. Click Load Button
5. If you saw the success message, it installed successfully.
   Your sessions are now being recorded in the background.
```

### Uninstall

```markdown
1. Open Photoshop
2. File > Scripts > Script Events Manager
3. Remove all events with PhotoshopSessionManager.jsx
4. Click Done Button
5. Search and delete the "photoshop_session_manager.files" file or 
   go to C:\Users\\[USERNAME]\AppData\Roaming\ and delete 
   photoshop_session_manager.files file.
```
